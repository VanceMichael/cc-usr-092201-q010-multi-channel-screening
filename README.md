# 多渠道电影展映编排

描述影片多渠道授权、母版、场地和实际放映资料, 并提供排期编排器。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。当前记录类型包括影片母版、放映授权、场地设备、排片场次、座席名额、放映回执，状态示例为待适配 → 已排片 → 可开放 → 需调整 → 放映中 → 已核销，取消的场次进入已取消。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

已整理的业务事实：

- 电影节设置影院、线上、户外和校园四类放映板块
- 活动计划展映数百部影片
- 部分场次面向公众提供惠民服务
- 部分版权仅允许线下两场放映
- 部分母版无法在户外设备上播放
- 放映结束后版权方可逐场核对实际播放与已消耗权利

## 编排器

`orchestration` 包实现多渠道展映编排的核心流程：

- 排期即校验：登记场次时立即核对影片母版、字幕、分级提示、场地设备、地域时段授权、映后嘉宾与惠民座席，适配问题提前交给技术人员
- 原子确认：确认排期的同时锁住实际版权次数与场馆资源，校验不通过则不产生任何锁定
- 局部调整：母版失败、嘉宾改期、户外取消、地域收紧、换厅、退票只牵动相关场次，任何重排都不会突破授权
- 发布不变量：对外发布的场次名额恒等于可售与免费名额之和
- 放映核销：放映结束后生成回执，版权方可逐场核对实际播放、观众容量与已消耗的权利

```python
from orchestration import Orchestrator

orch = Orchestrator()
# 登记母版、授权、场地、嘉宾后:
#   plan_session 登记排期并立即校验
#   confirm_session 原子锁住授权次数与场馆资源
#   open_session 发布场次, reconcile 放映后核销
#   licensor_report 输出版权方逐场对账单
```
