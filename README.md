# 多渠道电影展映编排

描述影片多渠道授权、母版、场地和实际放映资料。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。当前记录类型包括影片母版、放映授权、场地设备、排片场次、座席名额、放映回执，状态示例为待适配 → 已排片 → 可开放 → 需调整 → 放映中 → 已核销。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

已整理的业务事实：

- 电影节设置影院、线上、户外和校园四类放映板块
- 活动计划展映数百部影片
- 部分场次面向公众提供惠民服务

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态和事实说明。后续服务应继续兼容这份公开资料约定。
